# ข้อความโฆษณา + ค่าตั้งแคมเปญ Meta (Click-to-Messenger)

สินค้า: ebook "แฟนฝรั่ง ไม่ต้องรอดวง" 129฿ · ขายปิดในแชท Messenger
กติกาคำ: **ห้าม** "จับฝรั่ง / หาสามีรวย / ผัวฝรั่ง / การันตีได้แฟน" · **ใช้** "คุยกับต่างชาติ / มั่นใจ / ปลอดภัย / คัดคนจริงจัง"

---

## 1) โครงสร้างแคมเปญ (ตั้งตามนี้ใน Ads Manager)

| ระดับ | ค่าที่ตั้ง |
|---|---|
| Campaign objective | **Engagement** → Conversion location: **Messenger** (หรือ Sales → Messenger เมื่อมี Conversions API แล้ว) |
| Campaign name | `TF-EBOOK-CTM-[เดือน]` |
| Budget | ตั้งที่ระดับ Campaign (Advantage+ budget) เริ่ม **2,000฿/วัน** วันที่ 1–4 → **5,000฿/วัน** เมื่อ CPA ≤ 90฿ |
| Ad set 1 `BROAD-F-25-45` | หญิง 25–45 · ทั้งประเทศไทย · ไม่ใส่ interest (ให้ระบบหาเอง) · Placement: Advantage+ |
| Ad set 2 `INT-DATING-F-25-45` | หญิง 25–45 · Interest: Online dating, Tinder, Bumble, English language, Expatriate, Travel · ทั้งประเทศ |
| Ad set 3 `BKK-METRO-F-27-40` | หญิง 27–40 · กรุงเทพฯ+ปริมณฑล ชลบุรี เชียงใหม่ ภูเก็ต (รัศมี 40 กม.) |
| Ad set 4 `RETARGET-MSG-30D` (เปิดวันที่ 5) | Custom Audience: คนที่ส่งข้อความหาเพจใน 30 วัน **ยกเว้น** คนที่ซื้อแล้ว (อัปโหลดรายชื่อผู้ซื้อ/ใช้ event Purchase) · งบ 15% ของทั้งหมด · ใช้ครีเอทีฟโปร 99฿ |
| Optimization | Conversations (Messaging conversations started) |
| Message template | ใช้ "Start conversations" แบบ **คำถาม/ปุ่ม 3 ปุ่ม**: `📘 ดูในเล่มมีอะไร` / `💳 ซื้อเลย 129฿` / `❓ ถามก่อน` (ต้องตรงกับ keyword ในบอท) |
| Ads ต่อ ad set | 6 ครีเอทีฟ (A1–A3, B1–B3) × 2 ขนาด → ใช้ Advantage+ creative/placement asset customization: 1:1 สำหรับ Feed, 9:16 สำหรับ Stories/Reels |
| Schedule | ตลอดวัน (หากงบจำกัด: 11:00–23:00) |
| Attribution | 7-day click, 1-day view |

**กฎการตัดสินใจ (เช็กทุกเช้า 09:00)**
- CPA (ค่าแอด ÷ ยอดซื้อจริงจากแชท) ≤ 90฿ → เพิ่มงบ +20% (ไม่เกิน 1 ครั้ง/วัน)
- CPA 90–120฿ → คงงบ สลับครีเอทีฟที่แย่สุดออก 1 ตัว
- CPA > 120฿ 2 วันติด → หยุด ad set นั้น เปลี่ยนครีเอทีฟชุดใหม่
- Cost per conversation > 35฿ → ครีเอทีฟไม่ดึงดูด เปลี่ยน hook
- Conversation → ซื้อ < 20% → ปัญหาอยู่ที่บอท/ราคา/ข้อความ ไม่ใช่แอด (แก้บอทก่อน ห้ามเพิ่มงบ)
- Frequency > 3 ใน 7 วัน → ครีเอทีฟล้า เปลี่ยนชุด

## 2) ข้อความโฆษณา (Primary text / Headline / Description)

### มุม A — "ภาษา" (ใช้กับรูป A1–A3)

**A1 — หยุดทัก Hi**
- Primary text:
  > ทักฝรั่งว่า "Hi" แล้วเงียบทุกที? 🙈
  > เพราะข้อความแรกของคุณไม่มี "ตะขอ" ให้เขาคุยต่อ
  > ลองแบบนี้แทน 👇
  > "Okay, important question: have you tried som tam yet? 🌶️"
  > ในเล่ม "แฟนฝรั่ง ไม่ต้องรอดวง" มีประโยคแบบนี้ 60+ ประโยค พร้อมคำแปล ก๊อปไปวางได้เลย
  > 💬 ทักแชทรับเล่ม 129฿ ได้ไฟล์ทันที
- Headline: `60+ ประโยคคุยกับฝรั่ง ก๊อปวางได้เลย`
- Description: `คู่มือ 30 วัน · 129฿ · ส่งไฟล์ในแชททันที`

**A2 — ภาษาไม่เก่ง**
- Primary text:
  > ภาษาอังกฤษไม่เก่ง ไม่ได้แปลว่าคุยกับต่างชาติไม่ได้ 💛
  > ประโยคเดียวที่ทำให้เขาใจเย็นกับคุณ:
  > "Sorry, my English isn't perfect. Can you say that in a simpler way?"
  > เล่มนี้เขียนให้คนที่ "อ่านพอได้ แต่พิมพ์ไม่มั่นใจ" ทุกประโยคมีคำแปลไทย + วิธีใช้แอปแปลให้ดูเป็นธรรมชาติ
  > 💬 ทักแชท 129฿
- Headline: `คุยกับต่างชาติได้ แม้ภาษาไม่เก่ง`
- Description: `ประโยคพร้อมคำแปล + แผน 30 วัน`

**A3 — แมตช์แล้วเงียบ**
- Primary text:
  > แมตช์ก็เยอะ แต่คุยได้ 3 ข้อความก็หาย?
  > ปัญหาไม่ใช่หน้าตา แต่คือ Bio กับข้อความแรก
  > ในเล่มมี: เทมเพลต Bio 6 แบบ (มีแบบคุณแม่เลี้ยงเดี่ยว / ภาษาไม่เก่ง) + สูตรข้อความแรก "สังเกต 1 + ถาม 1"
  > 💬 ทักแชท 129฿ อ่านในมือถือได้เลย
- Headline: `Bio 6 แบบ + ประโยคเปิดแชทที่ได้คำตอบ`
- Description: `129฿ · รับไฟล์ในแชท`

### มุม B — "ปลอดภัย/กันโกง" (ใช้กับรูป B1–B3)

**B1 — ประโยคมิจฉาชีพ**
- Primary text:
  > ถ้าคนที่คุยอยู่พูดประโยคนี้ ให้หยุดทันที ⚠️
  > "I sent you a gift, but customs need a fee"
  > ปีที่แล้วมีคนไทยเสียหาย 21.9 ล้านบาท จากแชทที่เริ่มแบบนี้ (ข่าว ธ.ค. 2025)
  > เล่ม "แฟนฝรั่ง ไม่ต้องรอดวง" มีเช็กลิสต์ "เขาตัวจริงไหม" + กฎเหล็ก 7 ข้อ + สิ่งที่ต้องทำทันทีถ้าโดน
  > อยากมีแฟนต่างชาติได้ แต่ต้องปลอดภัยก่อน 💬 ทักแชท 129฿
- Headline: `เช็กลิสต์กันหลอกรัก + คัดคนจริงจัง`
- Description: `เล่มนี้เน้นปลอดภัย ไม่ขายฝัน`

**B2 — 3 คำถาม**
- Primary text:
  > ถามฝรั่ง 3 คำถามนี้ในสัปดาห์แรก จะรู้เลยว่าเขาจริงจังหรือแค่มาเที่ยว
  > 1) Are you living in Thailand, or just visiting?
  > 2) What are you looking for here?
  > 3) ... (อยู่ในเล่ม 😉)
  > พร้อมตารางสัญญาณเขียว 🟢 / สัญญาณแดง 🔴 และกฎ "3 สัญญาณแดง = Unmatch"
  > 💬 ทักแชท 129฿
- Headline: `3 คำถามคัดคนจริงจัง`
- Description: `คู่มือเดทกับต่างชาติแบบมั่นใจ`

**B3 — กลัวโดนหลอก**
- Primary text:
  > อยากมีแฟนต่างชาติ แต่เห็นข่าวโดนหลอกแล้วไม่กล้า?
  > ความกลัวแก้ได้ด้วย "ระบบ" ไม่ใช่ดวง
  > ในเล่ม: กฎเหล็ก 7 ข้อ · วิธีค้นรูปย้อนกลับ · ทำไมต้องวิดีโอคอลก่อนผูกพัน · เบอร์ที่ต้องโทรถ้าโดน
  > เขียนสำหรับผู้หญิงไทยที่อยากได้ความสัมพันธ์จริง อย่างปลอดภัย
  > 💬 ทักแชท 129฿
- Headline: `อยากมีแฟนต่างชาติ แบบไม่โดนหลอก`
- Description: `กฎเหล็ก 7 ข้อ + แผน 30 วัน`

### ครีเอทีฟ Retarget (ad set 4) — ใช้รูป A1 หรือ B1
- Primary text:
  > เมื่อวานทักมาแล้วยังไม่ได้รับเล่มใช่ไหมคะ 💛
  > วันนี้พิเศษสำหรับคนที่เคยทัก: 129฿ → **99฿** + แถม Chat Cards 100 ประโยค

## 3) ข้อความต้อนรับใน Messenger (ตั้งที่ตัวแอด)
- Greeting: `สวัสดีค่ะ 💛 อยากดูอะไรก่อนดีคะ?`
- ปุ่ม 1: `📘 ดูในเล่มมีอะไร` → บอทส่งสารบัญย่อ + รูปตัวอย่าง 2 หน้า
- ปุ่ม 2: `💳 ซื้อเลย 129฿` → เข้า flow bump → QR
- ปุ่ม 3: `❓ ถามก่อน` → FAQ 5 ข้อยอดฮิต

## 4) สิ่งที่ต้องมีก่อนเปิดแอด (คนทำ)
1. สร้างเพจ Facebook ใหม่สำหรับสินค้านี้ (เพจที่มีในบัญชีตอนนี้เป็นแบรนด์อื่นทั้งหมด) ชื่อแนะนำ: **"แฟนฝรั่ง ไม่ต้องรอดวง"** หรือ **"Tidfun Dating EN"**
2. ผูกเพจเข้า Business Manager เดียวกับบัญชีโฆษณาที่จะใช้ (แนะนำบัญชี `education` 2885254735145531 หรือ `TH Acc1` 428091288008179 — ทั้งคู่ ACTIVE, THB, มีบัตรแล้ว)
3. ติดตั้ง chatbot Messenger + ระบบเช็กสลิป และตั้ง event `Purchase` ส่งกลับ Meta (Conversions API) เมื่อสลิปผ่าน
4. อัปโหลดรูป 12 ไฟล์ในโฟลเดอร์ `ads/` และข้อความด้านบน
5. ตั้งแคมเปญตามตาราง ข้อ 1 **สร้างแบบ Paused** แล้วกดเปิดเมื่อบอททดสอบผ่าน
6. ส่ง Ad Library ของตัวเองให้ผมดูหลัง 3 วัน (หรือเปิดสิทธิ์ให้ผมอ่าน insight) ผมจะปรับให้ตามกฎข้อ 1
