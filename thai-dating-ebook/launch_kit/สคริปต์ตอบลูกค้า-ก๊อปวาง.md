## 11. FAQ (ตอบสั้น แล้วชวนกลับไปซื้อ)
**ภาษาอังกฤษไม่เก่ง ใช้ได้ไหม**
```
ใช้ได้ค่ะ ทุกประโยคมีคำแปลไทย และมีบทสอนใช้แอปแปลให้ดูเป็นธรรมชาติ เขียนมาเพื่อคนที่ "อ่านพอได้ แต่พิมพ์ไม่มั่นใจ" ค่ะ 😊
```
**การันตีว่าได้แฟนไหม**
```
ไม่มีใครการันตีเรื่องหัวใจได้ค่ะ 🙏 แต่เล่มนี้ช่วยให้คุยเป็น คัดคนเป็น และปลอดภัยทุกขั้นตอน ไม่ขายฝันค่ะ
```
**คนอื่นจะรู้ไหมว่าซื้อ**
```
ไม่มีใครรู้ค่ะ ไฟล์ส่งในแชทนี้แชทเดียว ไม่มีโพสต์ ไม่มีแท็กค่ะ
```
**คืนเงินได้ไหม**
```
ได้ค่ะ อ่านแล้วไม่ได้อะไรเลย ทักมาขอคืนภายใน 7 วันได้เลยค่ะ
```
**เป็นแม่เลี้ยงเดี่ยว / อายุ 40+ ใช้ได้ไหม**
```
ได้ค่ะ ในเล่มมี Bio สำหรับคุณแม่เลี้ยงเดี่ยวโดยเฉพาะ และใช้ได้ทุกวัยที่อยากมีความสัมพันธ์จริงจังค่ะ 💛
```
**ต่างจากคลิปฟรียังไง**
```
คลิปให้ทีละเคล็ดลับค่ะ ในเล่มคือระบบครบตั้งแต่ทำโปรไฟล์ แชท คัดคน เดทแรก ไปจนถึงคุยเรื่องเงิน/ครอบครัว พร้อมแผนทำทีละวัน 30 วันค่ะ
```
**ผู้ชาย / LGBTQ+ ใช้ได้ไหม**
```
ใช้ได้ค่ะ ประโยคแชท การคัดคน และการกันมิจฉาชีพใช้ได้ทุกคน แค่ตัวอย่างในเล่มส่วนใหญ่เขียนจากมุมผู้หญิงค่ะ
```
**อ่านบนมือถือได้ไหม / ได้ไฟล์ยังไง**
```
ได้ค่ะ เป็นไฟล์ PDF ส่งลิงก์ในแชทนี้ทันทีหลังโอน เปิดอ่านในมือถือได้เลยค่ะ
```
**แพง / ขอลด**
```
เข้าใจค่ะ 😊 129฿ ถูกกว่ากาแฟ 2 แก้ว แต่ใช้ได้ทุกครั้งที่คุย และมีรับประกันคืนเงิน 7 วันด้วยนะคะ
```

## กฎทองของแอดมิน
- ตอบภายใน **5 นาที** (คนที่ทักจากแอดหายเร็วมาก)
- ทุกข้อความจบด้วย **คำถาม หรือปุ่มให้ทำต่อ 1 อย่าง**
- **ห้ามสัญญาผล** ("ได้แฟนแน่นอน") และห้ามใช้คำว่า "จับฝรั่ง / หาผัวรวย"
- ตามลูกค้าได้แค่ **ภายใน 24 ชม.** หลังลูกค้าทักล่าสุด (กฎ Messenger)
- จดยอดลง `daily_tracker` ทุกวัน 09:00 และ 18:00
